Recommended implementation shape

Approach 1: Lightweight carousel, real reminders, placeholder cards

This is the recommended first pass. It uses a horizontal row inside the dashboard area. The Reminders card reads cached upcoming reminders and shows the top two. Finance and Ask AI are styled placeholders, marked Soon.

Approach 2: Full dashboard framework now

Create a reusable module registry and per-module view models immediately. More scalable, but heavier than the app needs before Finance and AI exist.

Approach 3: Reminder-only dashboard now

Very simple and data-pure, but it loses the useful roadmap effect you asked for.

Recommendation

  • Build Approach 1.
  • Keep Settings as the place for manual sync and server controls.
  • Use real reminder cache data; fall back to an empty reminder message if none exist.
  • Use placeholders for Finance and Ask AI without backend wiring.
  • Keep recording state compact: only show timer and stop affordance when recording.
