Proposed Behavior

  • Left/right arrows move the displayed range to the previous or next month when `Month` is selected.
  • Each reminder gets a deterministic colour from a broad palette, based on reminder id, so category is not required.
  • If a day has 2, 3, or 4 items, the map square is divided into 2, 3, or 4 equal vertical colour slices.
  • If a day has more than 4 items, we can show the first 4 colours plus a tiny `+N` indicator in the cell.
  • Multi-day reminders colour every covered day using that reminder’s colour.
  • The bottom map is shorter than v1, leaving more readable list space.

Implementation note: this can replace the current separate Month/Week/List views with one agenda-map screen and a range selector.
