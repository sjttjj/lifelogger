Design Candidate

  • Use subtle unboxed chevrons for previous/next month.
  • Keep one combined calendar screen with `Week / Month / All` range modes.
  • Give each reminder/event its own deterministic colour from a broad palette.
  • Split same-day map cells into equal colour slices up to four items.
  • For more than four items, show the first four colour slices plus a tiny `+N` marker.
  • Keep the bottom month map compact and persistent over the scrollable list.

If this version looks right, I can write the short spec and then implement it in the app.
